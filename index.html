พิธีกร AI
ไลฟ์ขายของบน TikTok แทนคุณ

AI เขียนบทขายจากสินค้าในไลฟ์ พูดเป็นเสียงไทย ตอบคอมเมนต์เรียกชื่อลูกค้า และปักตะกร้าให้เอง ส่งสัญญาณขึ้นไลฟ์ตรงโดยไม่ต้องใช้ OBS

ดาวน์โหลดสำหรับ Windows
Windows 10/11 (64-bit)

เริ่มใช้งานใน 4 ขั้น

  1. ดาวน์โหลดและติดตั้งดับเบิลคลิกไฟล์ AI-Araiwa-Setup แล้วกดถัดไปจนเสร็จ
  2. เข้าสู่ระบบ Licenseใส่ชื่อผู้ใช้ รหัสผ่าน และ License Key ที่ได้รับ
  3. เตรียมไลฟ์ใส่ API Key, ล็อกอิน TikTok, ดึงสินค้าจาก LIVE Manager, เลือกเสียงและพิธีกร
  4. ขึ้นไลฟ์ซ้อมในห้องไลฟ์ก่อน แล้วกด “ขึ้นไลฟ์” ระบบทำที่เหลือให้

ถ้า Windows ขึ้นหน้าจอสีน้ำเงิน “Windows protected your PC” ให้กด More info แล้วกด Run anyway — ขึ้นเฉพาะครั้งแรกที่ติดตั้ง หลังจากนั้นโปรแกรมอัปเดตตัวเองอัตโนมัติ

ทำอะไรได้บ้าง

AIเขียนบทและพูดขายเองวนขายสินค้าทีละชิ้น ไม่ซ้ำมุก เลือกบุคลิกพิธีกรได้
ไทยเสียงพากย์ไทย 10 เสียงเสียงธรรมชาติ ฟังตัวอย่างก่อนเลือกได้
แชทตอบคอมเมนต์เรียลไทม์เรียกชื่อลูกค้า ตอบคำถามสินค้า ขอบคุณคนกดติดตาม
ตะกร้าปักตะกร้าอัตโนมัติปักตามที่ AI พูด หรือผู้ชมพิมพ์ “ตะกร้า 3” แล้วปักให้
LIVEไลฟ์ตรงไม่ต้องใช้ OBSสร้างห้องและส่งสัญญาณให้เอง ไลฟ์พร้อมกันได้ 2 บัญชี
สรุปรายงานหลังไลฟ์ยอดคอมเมนต์ คำถามยอดฮิต สินค้าที่ถูกพูดถึง

ความต้องการของเครื่อง

  • Windows 10 หรือ 11 (64-bit)
  • RAM 8 GB ขึ้นไป (ไลฟ์ 2 บัญชีพร้อมกัน แนะนำ 16 GB)
  • อินเทอร์เน็ตอัปโหลด 10 Mbps ขึ้นไปต่อ 1 ไลฟ์
  • บัญชี TikTok ที่ไลฟ์ผ่าน LIVE Manager ได้
  • Google Gemini API Key (สร้างฟรีที่ aistudio.google.com)
